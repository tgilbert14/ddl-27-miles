# 27 Miles to Canada

An interactive Desert Data Labs field ascent up Arizona's Catalina Highway.
Scroll from Sonoran desertscrub at 2,700 feet to Mount Lemmon's mixed-conifer
summit at 9,157 feet while the road, vegetation, modeled temperature, and
elevation transform together.

**Live experience:** https://tgilbert14.github.io/ddl-27-miles/

## Highlights

- Six biotic communities driven by one mile-by-mile route model
- Procedural Canvas landscape and perspective highway
- Windy Point look-back control and summit climate comparison
- The real Summerhaven descent in the elevation profile
- Slow, interruptible Auto Ascent mode
- Responsive, keyboard-accessible, reduced-motion, and no-JavaScript editions

## Build

The experience is dependency-free. Source fragments live in `src/`; running
`node build.js` produces the deployable `index.html`.

Scientific claims and editorial guardrails are documented in
[`docs/grounding-bible.md`](docs/grounding-bible.md).
